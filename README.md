DNA Sequence Analyzer

A simple Python-based tool for analyzing DNA sequences. This project performs basic sequence analysis and provides useful information about a given DNA sequence.

Features

- Validates a DNA sequence
- Calculates GC content
- Finds mutations
- Searches for motifs
- Finds the longest and shortest sequences
- Sorts DNA sequences

Technologies Used

Python | Google Colab

Input

The program takes DNA sequences as input from the user.

Output

The analyzer displays the results of the selected analysis, such as GC content, sequence validity, motifs, mutations, and sequence-related information.

Purpose

This project was created to practice Python programming concepts while applying them to basic bioinformatics and DNA sequence analysis.
